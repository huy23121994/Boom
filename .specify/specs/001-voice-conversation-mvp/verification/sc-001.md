# SC-001 Manual Walkthrough

## Criterion

> Median end-to-end turn latency (VAD `onSpeechEnd` → first TTS audio byte) ≤ 3 000 ms across 10 turns. If p95 ≥ 3 600 ms, escalate per research §10.

## How to run

1. `npm run dev` — open DevTools Console.
2. Tap to start. Complete ≥ 10 full turns (speak → AI replies).
3. The orchestrator logs four `[turn-perf]` lines per turn. Copy all lines from the console.
4. Compute: `TOTAL = ttsFirst - vadEnd` for each turn.
