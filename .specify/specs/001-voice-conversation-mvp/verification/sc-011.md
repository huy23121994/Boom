# SC-011 Manual Walkthrough

## Criterion

> While the bubble is in the `listening` state, no partial/interim transcript text from the learner's live speech appears on screen at any time. Only finalized turns (after the turn ends) may appear in the transcript.

## How to run

1. `npm run dev` — open in Chrome (Web Speech API works best here).
2. Tap to start. Wait for greeting.
3. Speak slowly and watch the screen during `listening` state.
4. Check: does any live speech text flicker or appear in the transcript or anywhere else on screen while you are speaking (before the turn ends)?
5. After the turn ends and AI replies, check: does the finalized learner text appear in the transcript correctly?
